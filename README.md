# James Best

## Om meg

Jeg er utdannet innen helse- og idrettsvitenskap med en PhD i treningsfysiologi, og har bred erfaring fra universitetssektoren, helsevesenet og offentlig sektor.

Gjennom karrieren har jeg arbeidet med forskning, undervisning, veiledning, prosjektutvikling og helsefremmende tiltak. Jeg har blant annet etablert og drevet et fysisk aktivitetsprogram for NAV-brukere, støttet forskningsprosjekter med dataanalyse og visualisering, og arbeider i dag med digitalisering, automatisering og forbedring av arbeidsprosesser.

Jeg er spesielt interessert i hvordan teknologi, data og automatisering kan brukes til å skape bedre tjenester, mer effektive arbeidsprosesser og bedre beslutningsgrunnlag.

Denne GitHub-profilen brukes til å dokumentere prosjekter innen dataanalyse, automatisering, digitalisering og Linux.
